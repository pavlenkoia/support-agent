# Wiki Schema

## Назначение
Фактическая база знаний клиентской поддержки.

## Правила
- Страницы содержат только проверяемые сведения о предметной области.
- Клиентские сценарии, примеры реплик, готовые ответы и правила распознавания намерений запрещены.
- Источники под `raw/` используются только для происхождения фактов и не входят в каталог страниц для LLM-навигации.
- При конфликте источников сохраняются обе версии, страница помечается `contested: true`.
