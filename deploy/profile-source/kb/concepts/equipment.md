# Одежда и прокат для прыжков

## Одежда и обувь
- Для прыжка требуется закрытая одежда и обувь с фиксацией голеностопа.
- Зимой прыжки возможны; требуется более тёплая одежда.

## Выдача снаряжения
- Очки, шлем, комбинезон и перчатки не выдаются. Их отсутствие само по себе не препятствует прыжку.

## Берцы
- Берцы можно взять в прокате на месте. При наличии собственной обуви с фиксацией голеностопа прокатные берцы не обязательны.
- Стоимость проката берцев можно узнать по телефону или на месте.
