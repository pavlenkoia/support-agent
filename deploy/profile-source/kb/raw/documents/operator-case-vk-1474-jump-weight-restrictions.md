Источник: обращение 1474 и сообщение оператора.

Клиент спросил: «Здравствуйте, скажите есть ограничения по прыжкам?»

Оператор уточнил по весу: «85 кг тандем прыжок, самостоятельный 90 кг.»

Оператор также ответил при превышении веса: «Свяжитесь с офисом, если у вас есть превышения веса +7 351 214-30-30, напрямую с инструкторами.»

Подтверждённые факты:
- Для тандемного прыжка ограничение по весу — до 85 кг.
- Для самостоятельного прыжка ограничение по весу — до 90 кг.
- Если есть превышение веса, нужно связаться с офисом по телефону +7 351 214-30-30.
