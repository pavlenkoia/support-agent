# Подтверждённые факты

- Для полёта двух человек при покупке на сайте оформляют два отдельных сертификата.
- Один сертификат рассчитан на одного человека.
- Сертификат не именной.
- После покупки сертификат распечатывают.
- Для использования сертификата записываются по телефону офиса.
