## Не переносится в Wiki

Следующие блоки являются поведением агента, а не бизнес-фактами:

- строки 15–18 — обязательность вызова инструментов;
- строки 20–29 — границы доказательности и стиль использования фактов;
- строки 30–49 — готовые формулировки и сценарная маршрутизация; перенесена только декларативная основа;
- строки 51–56 — механизм уточнения и готовый fallback;
- строки 62–74 — порядок применения календарного инструмента и сценарное построение ответа; факты расписания перенесены отдельно;
- строки 97–123 — приоритеты follow-up, примеры пользовательских фраз и готовые последовательности ответа; бизнес-факты каналов записи перенесены отдельно;
- строки 138–161 — ограничения генерации, формат ответа, приветствие и social-reply;
- весь специальный блок `vague-interest opening` строк 43–62 старого `KB_AGENT_PROMPT.md` — частный сценарий с примерами фраз и готовой basis, не факт.

## Проверка завершённости

Реестр считается закрытым только если:

1. каждая строка таблицы присутствует в канонической Wiki;
2. compiled runtime-profile собирается после последнего изменения;
3. prompts не содержат перечисленные бизнес-факты или сценарии;
4. release guard сравнивает production-profile с проверенным compiled-артефактом.
